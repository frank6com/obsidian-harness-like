## Get started

1. Install Harness Like from the [Obsidian community plugin directory](https://community.obsidian.md/plugins/harness-like) (desktop only).
2. Open plugin settings → Models, enter your API Key (DeepSeek endpoint pre-configured), add models and set a default.
3. Click the bot icon in the ribbon and try: "Count the notes in this vault."

> See the [Quick Start](/guide/quickstart) for details.

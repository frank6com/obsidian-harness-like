# 智能体与模型

## 智能体

三种内置模式：

| 模式 | 能力 |
| --- | --- |
| 对话模式 | 仅对话与读取信息（只读工具） |
| 修编模式 | 可读写笔记（默认） |
| 创造模式 | 完整能力，可创建/修改插件 |

**什么时候用哪个模式**：

- **对话模式**：只读提问——统计、搜索、总结、答疑；
- **修编模式**：读写笔记——写周记、整理清单、修改笔记内容；
- **创造模式**：创建/修改子插件——面板、命令、工具、图标等（见[通过对话创建插件](/zh/guide/plugin-agent)）。

- 面板工具栏点击智能体按钮（上拉菜单）切换；被禁用的模式不出现。
- **自定义智能体**：设置 → 智能体 →「＋ 添加自定义智能体」，弹窗中勾选能力白名单（只允许勾选的工具）；还可填写自定义「系统提示词（persona）」——英文撰写，非空时遮蔽该模式默认提示词，留空使用内置默认。
- **以模板创建**：内置模式不可直接编辑；点其行的「以此为模板创建」复制出可编辑副本（含当前生效的 persona 文本起步），原内置随时可回退。
- **提示词体系**：系统提示词分层组装——共享身份与安全底线（所有智能体一致）+ 智能体 persona + 回复语言指令（按 Obsidian 语言动态生成）+ 动态上下文。内置 persona 以英文 md 维护、随构建内联，回复语言不受影响。
- **默认智能体**：设置 → 智能体 →「默认智能体」下拉（只能选启用的）。

## 模型

- **多提供方（通道）**：设置 → 模型，每个通道 = 名称 + Base URL（OpenAI 兼容端点）+ API Key + 模型列表 + 参数。
- **获取模型**：点「从端点获取」，弹窗中搜索勾选（可直接输入新模型名添加为候选）；若端点提供模型元数据，会自动填入上下文窗口。
- **模型级默认**：任意模型可「设为默认」——新会话的兜底模型。
- **会话级切换**：面板工具栏模型按钮（上拉菜单）按会话记忆选择。
- 参数：temperature（滑块）、最大输出 token 数（0 = 端点默认；推理模型的思考与回答共享此配额，建议 ≥ 8192，过小会导致"思考很久却没有回答"）、输入上下文窗口（信息性记录）、自定义请求头（每行 `Header: value`）。

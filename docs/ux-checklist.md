# dsh-obsidian Chat 体验改进清单（最佳实践梳理）

> 状态：草案 v0.1（2026-08-14）｜ 依据：P0 实测反馈 + dsh Web GUI 体验对照 + 通用 agent 聊天 UX 最佳实践
> 优先级：P0.5（快速修复，低风险高感知）→ P1（体验完善）→ P2（深度体验）

---

## 0. 现状总评

P0 的 Chat 是"能用"的功能骨架：会话持久化、流式输出、工具卡片、绑定笔记、会话级写开关都已就位。核心缺口是**过程不可见**（思考/工具执行期间界面空白）与**细节粗糙**（列表不可收起、输入框单一、按钮无状态）。以下清单按感知度排序。

## 1. P0.5 快速修复（低风险高感知，建议最先做）

> **P0.5 实施记录（2026-08-14）**：✅ 1.1 阶段状态条/工具卡片实时状态/流式光标/错误重试；✅ 1.2 会话列表可收起（信息增强与管理操作未做，转 P1）；✅ 1.3 输入框自动增高/发送中禁用/三态按钮（含停止=abort 中止）；◐ 1.4 绑定区仍为按钮（选择器转 P1）。

### 1.1 过程状态呈现（对应你反馈的"思考过程无任何显示"）
- **阶段状态条**：发送后立即在消息流底部显示当前阶段——`思考中…` → `调用工具 write_note` → `等待审批…` → `完成`；工具循环多轮时显示 `第 2/4 轮`。
- **工具卡片实时状态**：工具调用卡片从"执行中（spinner + 工具名 + 参数摘要）"过渡到"成功/失败"，而不是等结果回来才一次性渲染。
- **流式光标**：assistant 气泡流式期间显示 `▍` 光标，结束即消失。
- **失败可见性**：LLM 错误直接在气泡内显示错误码与摘要 + 一个"重试"按钮（比当前"错误: ..."文本更可操作）。

### 1.2 会话列表
- **可收起**：列表栏加折叠按钮（窄屏自动收起），收起后会话切换走"最近会话"下拉或命令面板。
- **信息增强**：每项显示绑定笔记标记（`📌 笔记名`）、最后消息摘要（前 20 字）、相对时间；当前会话高亮。
- **管理操作**：右键/悬浮菜单：删除会话、重命名会话、复制为 Markdown。

### 1.3 输入框与发送按钮
- **输入框**：自动增高（1–6 行）；Enter 发送 / Shift+Enter 换行（设置页可配置）；**发送中禁用**，防止重复提交；**草稿保留**（切换会话不丢输入）。
- **发送按钮三态**：就绪（可发送）→ 发送中（spinner，禁用）→ **停止**（生成期间按钮变为停止图标，点击中止本次生成，需 agent 循环支持 AbortSignal——P1 补）。

### 1.4 绑定笔记体验
- 头部绑定区改为**选择器**（当前笔记 + 最近笔记下拉），而非单一"绑定当前笔记"按钮；绑定后显示笔记名 + 解除按钮。
- 会话切换时绑定状态跟随会话恢复显示（当前为内存态，P1 持久化）。

## 2. P1 体验完善

### 2.1 消息呈现
- [x] **Markdown 渲染**（2026-08-14）：气泡支持 Markdown 渲染（Obsidian 原生渲染器，含代码块/表格/主题样式）；流式期间纯文本+光标，结束后渲染
- [x] **消息复制**（2026-08-14）：消息悬浮"复制"按钮（复制原始 Markdown 文本）
- [ ] 消息操作：悬浮操作条（重新生成 / 编辑后重发 / 删除）
- [ ] 工具调用折叠：工具卡片默认折叠为一行摘要，点击展开参数与结果（长内容截断）

### 2.2 会话与上下文
- [x] **会话标题**（2026-08-14）：首条消息自动生成标题（截断），随 `session/meta` 事件落盘；列表显示标题而非 `session-1723…`
- [x] **绑定笔记持久化**（2026-08-14）：绑定随会话元信息落盘，重启/切换会话后恢复；会话列表显示绑定标记
- [x] **空状态引导**（2026-08-14）：无会话时显示示例问题（点击填入输入框）+ 未配置 Key 提示（一键跳设置）
- [ ] 上下文注入可视化：当前注入的笔记上下文在头部显示"已注入 N 字符"，可一键取消注入

### 2.3 长会话性能
- 消息列表**虚拟滚动**（仅渲染可视区域）；历史重放懒加载（先最近 N 条，向上滚动加载更早）。

## 3. P2 深度体验

- 消息流**分支/重试**：从任意消息 fork 出新对话（对齐 dsh 会话 fork 概念）。
- **多模型切换**：会话级模型选择器（配合设置面多提供方）。
- **语音输入**、**拖拽文件附件**（作为消息上下文注入）。
- **对话导出**：一键导出会话为 Markdown 笔记。
- 主题/密度偏好（紧凑模式、字号）。

## 4. 设置面补全计划（对照 dsh，P1/P2 后补）

P0 设置只有：BaseURL / API Key / 模型 / 审批默认模式。对照 dsh 的设置面，缺口清单：

| 分组 | 项 | 优先级 |
|---|---|---|
| 模型 | 多提供方配置（多个端点可切换）、temperature / top_p / max_tokens、上下文长度上限、请求超时与重试次数 | P1 |
| 审批 | 目录级白名单（可写目录）、工具级默认策略（ask/allow/deny 按工具）、grant 管理界面（查看/撤销单勾双勾） | P1 |
| 会话 | 保留策略（条数/天数自动清理）、导出/删除、默认绑定笔记行为 | P1 |
| 网络 | 代理设置、自定义请求头 | P2 |
| 凭据 | 系统钥匙串存储（当前 data.json 明文） | P2 |
| 数据 | 数据目录查看/一键清理、损坏会话日志归档 | P2 |
| 日志 | 日志级别、日志目录打开 | P1 |
| 界面 | 流式输出开关、Markdown 渲染开关、发送快捷键、通知开关 | P1 |

**第一批实施记录（2026-08-14）**：✅ temperature（滑块）+ max_tokens 透传；✅ grant 管理界面（列表 + 撤销）。未做：多提供方切换、目录级白名单、会话保留策略、日志级别。

## 5. 建议实施顺序

1. **P0.5 全组**（过程状态条 + 工具卡片实时状态 + 发送三态/禁用 + 列表可收起 + 输入框自动增高）——一次提交，体验感知最大。
2. P1 消息 Markdown 渲染 + 消息操作（日常使用频率最高）。
3. P1 会话标题 + 空状态引导 + 设置面第一批（模型参数、grant 管理）。
4. 其余按清单逐项消化，每项独立提交并记录验收。

> 本清单为活文档：每完成一项，把该项移到"已完成"并记录日期；新增反馈追加到对应分组。

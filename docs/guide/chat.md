# 对话面板

## 界面布局

- **头部**：折叠会话列表（☰）、新建会话、打开插件管理器。
- **会话列表**：显示标题与消息数，选中行高亮；悬浮可导出 Markdown 或删除会话。
- **消息区**：一次问答为一轮（用户消息 + 工具卡片 + 回答），轮次底部有「复制本段对话」；代码块保留独立复制按钮。
- **工具栏**：智能体选择、模型选择（上拉菜单）、「仅当前笔记」开关。
- **底部**：输入框（自动增高，Enter 发送 / Shift+Enter 换行）、发送/停止按钮。

## 功能要点

- **流式输出**：可在 设置 → 界面 关闭（等完整消息再显示）。
- **Markdown 渲染**：回答按 Markdown 渲染（官方渲染器，主题一致），可在设置中改为纯文本。
- **阶段状态条**：思考中 / 调用工具 / 等待审批 实时可见。
- **错误与重试**：请求失败会持久化错误消息并给出「重试」按钮。
- **中止**：生成期间发送按钮变为「停止」，点击中止本轮。

## 会话管理

- 会话自动持久化在 vault 的 `.obsidian/harness-like/sessions/*.jsonl`，重启后恢复。
- 导出目录可在 设置 → 会话 配置（默认 vault 根下的 `sessions/` 文件夹）。
- 会话保留天数（自动清理）同样在 设置 → 会话 设置。

## 界面语言

默认「跟随系统」：与 Obsidian 应用语言一致（zh → 中文，其余 → English）。可在 设置 → 界面 手动固定为中文或 English。
